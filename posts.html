How to publish

  1. Go to business.google.com → select the branch profile
  2. Add update → paste the post text
  3. Download the graphic from this page and attach it — check the branch name on the graphic matches the profile
  4. Set the button as noted on each post
  5. Link to speedyins.com, or speedyins.com/es.html for Spanish posts
  6. Publish

Where this data lives

This page reads from posts.json in the speedy-dashboard repo. The graphics are in img/posts/. The weekly automated task follows POSTS_TASK.md and records what went out in posts_log.json.

Nothing here lives in a chat or a downloaded file — change posts.json and both this page and the task pick it up.
